
# Project Documentation

## 1. Introduction

The Operational and Production Analytics Dashboard is a practice project developed using Microsoft Excel and Power BI.

It focuses on analysing manufacturing operations and presenting business insights through interactive dashboards.

## 2. Project Objectives

- Analyse production performance.
- Monitor machine utilisation and downtime.
- Understand inventory levels.
- Evaluate product quality.
- Analyse dispatch performance.

## 3. Tools Used

- Microsoft Excel
- Microsoft Power BI
- Power Query
- DAX

## 4. Data Preparation

The project uses a practice dataset organised into six worksheets:

- Production_Data
- Machine_Data
- Inventory_Data
- Quality_Data
- Dispatch_Data
- Calendar

## 5. Dashboard Structure

### Page 1: Executive Dashboard

Provides an overview of operational performance through KPIs and visualisations.

### Page 2: Production Analytics

Focuses on production trends and operational performance.

## 6. Learning Outcomes

- Data cleaning
- Data transformation
- Data modelling
- DAX measures
- KPI development
- Dashboard creation
- Business intelligence

## 7. Conclusion

This project demonstrates the practical application of Excel and Power BI in operational analytics and business intelligence.
